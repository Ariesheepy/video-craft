> 用法：TREATMENT 填完再填这张表。**每一行是一次剪切，不是一个想法。**
> 七列缺一列就会退回 PPT：缺「任务」→ 废镜头；缺「机位」→ 平面图；缺「前景」→ 没景深；缺「时长」→ 节奏靠感觉。

## 自查（填完立刻过一遍）

- [ ] **去掉所有元素入场动画，还剩运动吗？** 剩下的才是镜头内的运动。
- [ ] **相邻两镜是否至少改 2 项**（景别 / 角度 / 主体 / 背景 / 明暗）？连改 1 项 = 翻页。
- [ ] **有没有超过 4 秒且镜内无运动的镜头？** 有就切开或加推。
- [ ] **每镜的任务遮住还能看出它在干什么吗？** 看不出来说明这镜只是「展示信息」。
- [ ] **平均镜长**在 1.5–4.5 秒之间？（产品片可更短，讲解片不能更长）
- [ ] 有没有一镜是「正对镜头、物体居中、背景纯色」？——那是 PPT 构图，要么换角度要么加前景遮挡。
