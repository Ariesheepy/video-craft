## 七、反 PPT 承诺（逐条打勾）

- [ ] 单摄像机，全片所有镜头共用一台
- [ ] 至少三层景深，且前景真的遮挡
- [ ] 摄像机运动镜数 ≥ 60%
- [ ] 没有元素级淡入/飞入（要出现就 slam / 切 / 遮罩揭开）
- [ ] 相邻镜头至少改 2 项（景别/角度/主体/背景）
- [ ] 每镜的「任务」一列写得出来，且不是「展示信息」
- [ ] 文字面积 ≤ 15%，文字承载信息 ≤ 40%
