# 案例与实测（10 版对照：为什么"像 PPT"，以及怎么修）

> 这份是 [MOTION-RULES.md](MOTION-RULES.md) 的**证据册**。规则是结论，这里记结论是怎么被测出来的。
> 素材：同一个 15 秒虚构苹果（赤曜 AVEL R-07），**同一文案、同一色板（纸 `#EDE4D0` / 墨 `#141210` / 红 `#D52B1E`）、同一字体、同一渲染器**，只改"怎么拍"。全部在 `apple-ab/` 下。

## 一、十版一览

| 版本 | 怎么拍 | 硬切 | 平均镜长 | 文字面积 峰/均 | 构图中心率 | 动能量 | 结论 |
|---|---|---|---|---|---|---|---|
| **A** | 幻灯片：四页、居中、淡入 | 3 | 3.75s | 5.4% / 3.9% | **100%** | 0% | 最像 PPT，**但文字面积最低** |
| **B** | 9 个镜头，物体凭空出现 | 8 | 1.67s | **18.2%** / 5.4% | 33% | travel 3533 | 切得碎，更乱 |

| **D** | C + 三次反向 + 两次升降 | 0 | 15s | 17.8% / 6.9% | 43% | travel 6611 | 像"房间"了 |
| **E** | 机位锁死 + 全屏墨条扫过 | 0 | 15s | 6.4% / 1.5% | 0% | 0 | **仍被否：扫光＝换页** |

## 二、十条结论（每条都挂着证据）

1. **文字面积占比抓不住 PPT。** A 只有 5.4%（十版最低），却最像 PPT——因为幻灯片是"字少、字大、居中"。**这条指标一度被我当主判据，是错的。**
2. **构图中心率更可信。** A 是 100%（每个元素都在画面中心），其余版本 18–43%。规矩：**≤ 40%**。
3. **PPT 感的第一来源是"场景切换"**，不是配色、不是字体、不是转场。B 有 8 次切、物体在切点凭空出现，最乱。
4. **一镜到底会把"出现"逼成"位移"。** C 里所有元素必须在同一个空间里被"搬进来"——这一步就已经去掉大半 PPT 味。
5. **一镜到底 ≠ 一直往前走。** C 是单向推轨（观众说"只是滑轨视频"）；D 加了三次反向 + 两次升降，才像在一个房间里走。
6. **全屏扫掠仍然是换页。** E 用一条横贯全屏的墨条"印上再擦掉"，观众指出"红线扫过、元素立刻消失，跟场景切换没本质区别"。**整幅画面同一瞬间一起变＝换页**，不管画成什么。
7. **变化必须以"一件东西"为范围。** F 把每块内容变成实物（牌/纸卡/台纸/窗/标签），各自进出——这条是这次最大的收获，已写进 §3。
8. **工具尺度要匹配被操作的物件。** 擦的是 520×420 的板，刮刀就该是卡片高度；E 那条与画面同高的扫光，尺度上就是"整屏"。
9. **运镜能用，但要有上限。** G 的 travel 7380（一秒左一秒右）让观众重新定位；J 降到 237（只在换重点时倾身）就看不出"镜头在动"，只记得住内容。**位移 ≤350 px/s、一次一个方向**。
10. **节奏归音乐。** 没配乐时靠"结构"（幕/拍）；有配乐就跑 `_templates/beats.py` 把动作钉在拍点上（J 用 80.75 BPM / 0.743s 一拍，15s = 20 拍）。

## 三、踩过的坑（照着改就行）

| 症状 | 原因 | 修法 |
|---|---|---|
| 透视线从画面中间放射，穿过文字 | 灭点放在画面中心 | 灭点压到地平线以下（I 从 y=545 改到 762） |
| 刮刀画到物件外面 | 局部坐标当世界坐标用 | `drawSqueegee(t, sc, y, h, ox)` 加横向偏移参数；窗内传 0 |
| 离场的卡横穿别的物件 | 退场方向（向右）撞上后来的窗 | 改成向下撤（"从墙上取下来"） |
| 侧视图和正视图一模一样 | `appleFront` 忽略 `sx` 参数 | `applePath/halftone/gloss` 全部吃 `sx` |
| 苹果溢出窗框、轮廓被切掉 | 没 clip 或尺寸过大 | `rect().clip()` + 窗内 h 收到 236、`sx 0.86` |
| 三视图标签看不见 | 用纸色画在纸底上 | 改墨色 |
| 擦除结束后色块还在 | 擦完没 `return` | `if (t > erase.t0 + dur) return;` |
| 字幕被物件压住 | 物件与字幕同一层 | 字幕放屏幕层（`setTransform` 身份矩阵），物件在世界层 |
